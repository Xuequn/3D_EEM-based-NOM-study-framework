# Release notes

This release provides the computational workflow used in the associated manuscript. It includes:

- exact-coordinate alignment of EEM data to an 81 × 81 grid;
- zero-filled, mask-aware, and masked-convolution CNN inputs;
- leave-one-source-out evaluation;
- PLSR, random forest, XGBoost, and CNN comparisons;
- full-data RCPM fitting for interpretation;
- Grad-RAM and PCA feature extraction;
- MDA and Ward hierarchical clustering;
- Kruskal-Wallis epsilon-squared comparison for K = 2–8;
- generalized 2D-COS for the C1–C2 and C2–C3 transitions;
- separate reproducible environments for the RCPM and MDA stages.
